## About Me

I'm a Computer Science graduate with an MSc in Big Data Management and Analytics from Griffith College Dublin (First Class Honours, 1.1), based in Dublin, Ireland. I like building systems that hold up under real conditions: data pipelines that survive broker failures, dashboards that catch a data quality issue before it reaches a stakeholder, and encrypted file sharing that never touches plaintext data.

My background leans data engineering and analytics (Python, SQL, Kafka, Flink, Snowflake, dbt, Power BI) with backend development on the side (FastAPI, Java/Spring Boot). As a Data Analyst Intern at Taxilla IT, I built ETL pipelines, ran data quality checks across large datasets, and also built backend Java services with Spring Boot and Spring microservices. My MSc thesis is a blockchain-based data sharing platform built on Ethereum and IPFS, with end-to-end encryption so neither the backend nor the storage layer ever holds plaintext data.

I published a paper on secure group communication techniques at IEEE ICACCM 2022, and I'm currently looking for backend, data engineering, or full-stack roles where I can keep working on problems like these.
